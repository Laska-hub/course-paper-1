# Финансовый анализ транзакций

Проект позволяет анализировать личные финансовые данные, рассчитывать кешбэк, отслеживать расходы по категориям и дням недели, а также вести учет доходов и инвестиций.

## Возможности

- Загрузка и стандартизация данных транзакций.
- Расчет кешбэка по категориям (1% от суммы транзакции).
- Анализ расходов:
  - по категориям,
  - по дням недели,
  - по рабочим дням.
- Отчет по инвестициям с учетом доходов и расходов.
- Поиск транзакций:
  - по категории,
  - по номеру телефона,
  - по конкретному получателю перевода.
- Актуальные курсы валют и цены акций (для отображения на дашборде).
